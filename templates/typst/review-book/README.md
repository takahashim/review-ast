# review-book

A Typst book library for Japanese book typesetting. It provides a JIS-B5,
jlreq-style page design (type area derived from characters-per-line × type size
and lines × leading), running heads, an outer-edge folio, crop marks and a
hidden folio for print submission, and native heading / figure numbering.

It is shipped inside the [review-ast](https://github.com/takahashim/review-ast)
gem, which renders Re:VIEW manuscripts to Typst, and can also be used on its own
to hand-write a book in Typst.

## Using it standalone

Copy this directory into your project (or install it under a local package
namespace and import `@local/review-book:0.1.0`), then:

```typst
#import "review-book/lib.typ": book, default-theme

#show: book.document.with(
  metadata: (title: [手書きの本], language: "ja"),
  theme: default-theme,
)
#set heading(numbering: book.heading-numbering)

= 最初の章
本文。図は @fig1 のように参照できる。
#figure(image("fig.png"), caption: [サンプル図]) <fig1>
== 節
```

Headings, figures, tables and references are native Typst elements the theme
styles; `set heading(numbering: book.heading-numbering)` turns on Japanese
chapter numbering (第1章 / 1.1). A page number (folio) shows by default.

See `examples/minimal.typ` for front matter, main matter, appendix and back
matter, and the two design documents in the review-ast repository:

- `doc/design-hanmen.ja.md` — the page-design model and its values (theme.typ)
- `doc/typst-review-book.ja.md` — the library's API and the `book.*` / `review.*`
  split (§1.5 covers hand-written documents)

## Two public namespaces

- `book.*` — the stable API for hand-written Typst documents
- `review.*` — the Re:VIEW compatibility API, generated by review-ast; it
  delegates to `book.*`
